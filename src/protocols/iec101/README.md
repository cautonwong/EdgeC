# IEC 60870-5-101 协议深度指南

## 1. 协议本质：恶劣环境下的坚守者

IEC 101 是为低带宽、高干扰的串行链路设计的。其核心在于 **FT1.2 帧格式** 和 **非平衡传输模式**。

### 1.1 FT1.2 帧格式
*   **固定帧 (Fixed)**: `0x10 | C | A | CS | 0x16`。用于链路状态查询、复位、确认。
*   **可变帧 (Variable)**: `0x68 | L | L | 0x68 | C | A | ASDU | CS | 0x16`。承载业务数据。
*   **单字节 (Single)**: `0xE5`。确认收到。

**核心字段：**
*   **FCB (帧计数位)**: 防止丢包重发导致的重复处理。每发新帧翻转一次。
*   **ACD (一级数据请求)**: 从站置位，告诉主站“我有急事（1级数据），快来问我”。
