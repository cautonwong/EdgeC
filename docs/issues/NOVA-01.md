## What to build

Implement the `nova_core_app` frontend scaffold and aesthetic system. Establish a React/Vue project utilizing Vite. Define the "Utilitarian Cyber-Physical" design system: dark mode backgrounds, sharp neon accents, monospace typography for technical data, and a dense, grid-based layout. Configure the build pipeline to output assets directly to the EdgeC `web/` directory for hosting by the embedded C web server.

## Acceptance criteria

- [ ] A modern frontend project (React or Vue) is scaffolded.
- [ ] CSS variables or a Tailwind config are established for the Cyber-Physical color palette and typography.
- [ ] A basic shell layout (header, sidebar, main content area) is implemented adhering to the design system (no generic rounded UI).
- [ ] The Vite build command successfully outputs static assets to the EdgeC `web/` folder.
