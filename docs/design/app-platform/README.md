## 这组文档的写法约束

- 每份文档都区分**机制**、**验收**、**未决**。机制是打算怎么实现，验收是怎么证明它对，未决是还没答案的部分。
- 没有实测数据的地方不写数字结论，只写待测项。
- 任何"原子""隔离""一致"的字样，必须在同页给出失败时的行为。给不出，就说明这个承诺还不能写。
