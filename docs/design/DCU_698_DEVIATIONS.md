# DCU 698 标准与产品偏差登记

> 目的：把“标准怎么说、产品怎么做、为什么、什么时候复查”收在一处。新代码按标准；下列偏差必须有 DAR 诚实行为，不得伪造值。
> 依据：`docs/698.pdf` 与 `docs/698_parsed.md`；计划 `docs/plans/2026-11-21-dcu-698-production-plan.md` §12.5；实现证据在 `docs/evidence/DCU-*/`。完整缺口清单以计划 §12.5 为准，本表只收会反复被问到的口径。

## 规则

1. 标准清楚且产品无历史包袱时，按标准实现，不登记偏差。
2. 标准清楚、产品旧语义冲突时，偏差显式登记；新对象/新属性按标准，旧语义只做兼容层并标注。
3. 标准自身矛盾时，选类定义表作默认，登记 HOLD 与选择理由，等标准所有者确认。
4. 缺数据源或硬件映射时，登记 producer/映射缺口，先回 DAR 5/2，不造值。
5. 偏差行必须有复查条件；产品口径变化时先改本表，再改代码与验收。
