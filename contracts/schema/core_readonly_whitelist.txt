# Rule R-08 - modules/edge_core change approvals
#
# `modules/edge_core` and `include/contract_data_types.h` are protected assets:
# changes require explicit architecture sign-off. This file IS that sign-off.
#
# Format: one path per line, `#` starts a comment. Every entry must name the
# issue that justified it. `scripts/check_core_readonly.sh` fails a PR that touches
# a protected file without a matching entry, so an empty file means "frozen".

# made modules/edge_core a hard freeze and blocked the very refactors it protects
# (#410 audit §6.3). Adding an entry is a review decision, not a formality: review
# the diff for ABI and aggregate-encapsulation impact before adding one.
